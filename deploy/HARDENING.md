# Production hardening

Config artifacts for the hardened MobInspect production deployment (nginx→gunicorn,
systemd, PostgreSQL on a single host). Applied and verified end-to-end 2026-07-07.
These files mirror what is installed on the server; secrets are **never** stored here.

## Layout

| Repo path | Installed to | Purpose |
|---|---|---|
| `mobinspect-gencert` | `/usr/local/bin/` | Generate/refresh the self-signed TLS cert for the host's current IPv4 (`SAN=IP`). Re-run after a DHCP IP change. |
| `mobinspect-backup` | `/usr/local/bin/` | Nightly Postgres `pg_dump` (custom format) + app config/secret tar → `/var/backups/mobinspect/`, 14-day retention. |
| `mobinspect-healthcheck` | `/usr/local/bin/` | Poll `/healthz`; log to journald only on real DB/queue/HTTP failure. |
| `nginx/mobinspect` | `/etc/nginx/sites-available/` | `:443` TLS + `:80→301` redirect, security headers, `/static/` served by nginx. |
| `nginx/mobinspect-hardening.conf` | `/etc/nginx/conf.d/` | gzip types + vary. (`server_tokens off` is set in the main `nginx.conf`.) |
| `systemd/mobinspect-backup.{service,timer}` | `/etc/systemd/system/` | Daily 03:00 backup. |
| `systemd/mobinspect-healthcheck.{service,timer}` | `/etc/systemd/system/` | Health probe every 2 min. |
| `systemd/mobinspect-web.service.d/20-secrets.conf` | drop-in | `EnvironmentFile=/etc/mobinspect/secrets.env` (0600) + `MOBINSPECT_BEHIND_TLS=1`. |
| `systemd/mobinspect-web.service.d/20-hardening.conf` | drop-in | Sandbox + `MemoryHigh`/`OOMScoreAdjust`. |
| `systemd/mobinspect-qcluster.service.d/20-*.conf` | drop-ins | Same, tuned for the heavier async scan worker. |
| `ssh/01-mobinspect-hardening.conf` | `/etc/ssh/sshd_config.d/` | Key-only SSH (sorts **before** `50-cloud-init.conf`; sshd is first-match). |
| `logrotate/mobinspect` | `/etc/logrotate.d/` | Rotate `~/.MobInspect/debug.log` (copytruncate). |
| `journald/mobinspect.conf` | `/etc/systemd/journald.conf.d/` | Persistent journald, 500M cap. |

## NOT in git (managed on-host only)
- `/etc/mobinspect/secrets.env` (0600 root) — `POSTGRES_PASSWORD`, `MOBINSPECT_ADMIN_PASSWORD`.
- `/etc/ssl/mobinspect/mobinspect.{crt,key}` — generated by `mobinspect-gencert`.
- ALLOWED_HOSTS self-heal (`mobinspect-hosts-*`) — see the sibling files in `deploy/`.

## Notes
- Sandbox intentionally keeps `PrivateTmp`/`SystemCallFilter`/`MemoryDenyWriteExecute`
  **off** — the scanner forks jadx (JVM JIT needs W+X), apktool, adb and writes to
  `$HOME`/`/run`/`/tmp`.
- gunicorn keeps `--log-level=warning` + `--control-socket /run/mobinspect/gunicorn.ctl`
  (fork-deadlock mitigation) alongside `--max-requests` worker recycling.
- Firewall: ufw default-deny in, allow 22 (limit)/80/443; gunicorn (8000) and Postgres
  (5432) stay loopback-only.
