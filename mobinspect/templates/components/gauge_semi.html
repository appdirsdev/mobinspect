{% comment %} Thick 180° semicircle gauge — the CyberGuard reference's signature element (Dashboard.png "Firewall Activity"). Pure SVG/CSS, no JS charting and no per-value trig: the arc fill is the pathLength=100 + stroke-dasharray trick (same as components/gauge_arc.html), and the pointer dot is an SVG rotated about the gauge centre — so it scales exactly with the viewBox at any size. Deliberately NOT a reuse of gauge_arc.html: that gauge's pointer math and tick literals are hardwired to a 270° sweep and can't be retargeted to 180°. Params: value — 0..100 (required). Clamped visually by the arc; caller must pass a real number. color — CSS color for the arc / glow / pointer ring. Defaults to the amber data-viz accent (#FE4A23). Pass a NON-severity metric here so amber stays honest; for a security SCORE, pass `value|score_color` instead (semantic, theme-aware). unit — suffix after the centre number (default "%"). sub_label — small line under the number (e.g. "3 / 3 apps · 30d"). uid — unique suffix for the gradient/filter ids when more than one gauge is on a page (default "1"). size_class — width classes for the svg (default a responsive max-width). {% endcomment %}
