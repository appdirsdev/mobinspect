Run TLS/SSL Security Tests — {{ package }}

    
  

  

    

      
TLS/SSL Security test helps you evaluate the security of your application's network connections. These tests are applicable only for applications that perform network connections over HTTP protocol.

      
TLS Misconfiguration Test — Enable HTTPS MITM Proxy, Remove Root CA, Run the App for 25 seconds.

      Uncovers insecure configurations that allow HTTPS connections bypassing certificate/SSL errors in WebViews.

      
TLS Pinning/Certificate Transparency Test — Enable HTTPS MITM Proxy, Install Root CA, Run the App for 25 seconds.

      Evaluates the app's TLS/SSL hardening; checks for certificate/public key pinning or certificate transparency.

      
TLS Pinning/Certificate Transparency Bypass Test — Enable HTTPS MITM Proxy, Install Root CA, Bypass pinning or certificate transparency.

      Tries to bypass certificate/public key pinning or certificate transparency controls.

      
NOTE: For better results, while the app is running, navigate through different flows that trigger network connections over HTTP. Make sure no other apps are running during the test.
