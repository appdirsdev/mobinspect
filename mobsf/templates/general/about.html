{% icon "shield" size=17 %} What it does

MobInspect is a security research platform for mobile applications on Android, iOS, and Windows Mobile. The static analyzer supports APK, AAB, XAPK, IPA, APPX, and source-code archives. The dynamic analyzer covers both Android emulators and iOS (Corellium VMs and jailbroken hardware), with Frida instrumentation, live API monitoring, and network traffic capture.

MobInspect ships with a modern Tailwind UI, dynamic role-based access control, per-user revocable API keys, and an analytics dashboard on top of a mature analyzer stack.

Supported formats

APK· AAB· XAPK· IPA· APPX· Source archive

Dynamic targets

Android emulators· iOS Corellium VMs· iOS jailbroken hardware· Frida instrumentation
